Hola 올라 소개

🌍 서비스 소개

Hola(올라)는 AI가 생성한 실전 스페인어 문장으로 학습하는 웹 서비스입니다. 여행 단계별 난이도로 구성되어, 초보부터 중급 이상까지 자신의 수준에 맞는 학습이 가능합니다.

📖 사용 방법

1
단계 선택

도착(기초) → 현지 탐험(중급) → 현지인(고급) 중 선택

2
문장 학습

AI가 만든 문장을 읽고, 🔊 버튼으로 발음을 들어보세요

3
발음 연습

🎤 버튼을 눌러 따라 말하면, 내 발음과 비교할 수 있어요

4
단어 탐구

문장 속 단어를 클릭하면 뜻과 활용 예문을 볼 수 있어요

🛠️ 기술 스택

HTML / CSS / JavaScript Vercel Serverless (Python) OpenAI GPT-4o-mini Web Speech API

⚠️ 참고 사항

발음 체크 기능은 브라우저의 Web Speech API를 사용합니다. Chrome 브라우저에서 가장 잘 동작하며, 일부 브라우저에서는 지원되지 않을 수 있습니다.
